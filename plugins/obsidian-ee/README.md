# obsidian-ee (plugin)

E2E encrypted collaborative editing for Obsidian. The plugin loads a WASM module
compiled from the `collab-wasm` crate.

## Prerequisites

- Rust + `cargo` (https://rustup.rs/)
- `wasm-pack`
- The WASM target: `rustup target add wasm32-unknown-unknown`

## Clean checkout

```bash
npm ci && npm test
```

`npm test` and `npm run build` auto-build the WASM module via the `build:wasm`
hook (`pretest` / `prebuild`) — no manual build step.

## WASM artifacts

The compiled module in `src/wasm/` is generated by `scripts/build-wasm.sh`,
gitignored, and never committed. Delete it any time; the next `npm test` or
`npm run build` regenerates it.
